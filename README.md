# Online Communities: Contact Page

A contact form page built with React and Vite. There's no backend, so submitting the form only shows a confirmation message.

## Requirements

- [Node.js](https://nodejs.org/) 20.19 or newer

## Setup

```bash
npm install
```

## Run locally

```bash
npm run dev
```

Then open the URL shown in the terminal (usually http://localhost:5173).

## Build

```bash
npm run build
```

The production files go to `dist/`. To preview the build locally:

```bash
npm run preview
```
